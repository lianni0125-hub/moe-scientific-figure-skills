# 萌！美少女科研作图 Skills

> **Moe Scientific Figure Skills — Scientific visualization styles, personified.**

## 把科研图画好，是少女们的超能力！

这是一个持续更新的科研作图风格库。每位看板娘代表一套可复用的 visual language：不只包含一组好看的颜色，还包括信息层级、版式节奏、线条语气，以及颜色与科学语义之间的稳定映射。

选择最符合论文气质的角色，阅读她的 Skill，然后让整套论文插图保持同一种视觉人格。

## How to use

1. 根据论文的 argument structure，而不是个人最喜欢的颜色，选择一个 Skill。
2. 将对应的 style folder 交给支持 Skills 的 coding agent，或直接参考其中的设计规则。
3. 在出图前先建立 semantic colour registry：一个科学概念对应一个稳定颜色角色。
4. 在论文最终栏宽下检查字号、留白、箭头、图例和 colour-blind legibility。

根目录的 [SKILL.md](SKILL.md) 可作为总路由器；每种风格也可以单独使用。详细的共同规则见 [Scientific Figure Principles](references/scientific-figure-principles.md)。

## Growing collection

持续更新中。后续会继续增加新的科研图气质、色系与看板娘；新风格应当拥有独立的 scientific use case，而不只是换一套颜色。

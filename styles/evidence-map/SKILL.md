# Evidence Map

Use this style for event chains where different observations provide different strengths or kinds of evidence.

## Visual language

- Arrange evidence as a directed sequence or structured map.
- Use deep blue for the initial state and teal for confirmation.
- Keep passive observation in slate to avoid overstating it.
- Use coral for an exceptional change and amber for a marked revision.
- Reserve violet for the downstream outcome.

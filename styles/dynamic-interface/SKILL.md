# Dynamic Interface

Use this style when the figure explains how an entity or system changes across states.

## Visual language

- Compose the figure as a readable sequence of states.
- Use crisp rounded modules, visible connectors, and generous internal padding.
- Give the stable entity a continuous teal cue across panels.
- Reserve coral for attention, change, or the critical contrast.
- Use indigo and blue for structure rather than filling every surface.

## Palette

| Role | Colour |
|---|---|
| primary structure | #2F3C7E |
| secondary structure | #4F73C9 |
| continuity | #2AAFA1 |
| attention / change | #F28C6F |
| background | #F7F4EE |

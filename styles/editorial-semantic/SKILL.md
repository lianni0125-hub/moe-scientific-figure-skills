# Editorial Semantic

Use this style when a figure distinguishes preserved alternatives from selected and excluded pathways.

## Visual language

- Organise the figure around a visible fork, branch, or decision boundary.
- Use forest for alternatives retained or information preserved.
- Use gold for the selected or supported pathway.
- Use wine for exclusion, loss, or error.
- Keep the tone editorial and scholarly with warm neutral structure.

## Palette

| Role | Colour |
|---|---|
| alternatives retained | #246354 |
| selected / supported pathway | #D0A23A |
| excluded / erroneous outcome | #8F3D4A |
| context structure | #C9C2B8 |

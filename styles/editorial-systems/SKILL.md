# Editorial Systems

Use this style for layered systems or related mechanisms that must remain visually distinct.

## Visual language

- Build two clearly separated but connected system regions.
- Use editorial spacing, thin rules, and direct labels.
- Map the primary layer or mechanism to indigo.
- Map the contrasting layer or mechanism to amber.
- Use blue-grey only for secondary structure.

## Palette

| Role | Colour |
|---|---|
| primary layer / mechanism | #344B8E |
| contrasting layer / mechanism | #D39A35 |
| secondary structure | #8EA6AE |
| text and rules | #30343B |

# 萌！美少女科研作图 Skills

> **Moe Scientific Figure Skills — Scientific visualization styles, personified.**

## 把科研图画好，是少女们的超能力！

本仓库把科研作图风格做成可以持续扩展的“双语图鉴”。英文保留准确、便于复用的风格名与设计术语；中文负责直观解释每套 Skill 的气质、适用场景和色彩语义。

这里的 Palette 不是装饰性配色包。每套 Skill 都同时规定：

- 哪类科学信息适合这种视觉气质；
- 哪些颜色分别承担主张、条件、结果、异常或背景角色；
- 信息层级、线条、箭头、标注和留白应如何组织；
- 如何避免“同色不同义”和只靠颜色区分信息。

使用方法与完整 Gallery 请见 [README](README.md)。本项目会持续更新，不止六种风格。
